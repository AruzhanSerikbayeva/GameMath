АЙЗЕРЕНІҢ ШАҢҒЫ ЖАРЫСЫ — «Санның квадраты және кубы» (49-сабақ)
================================================================

ҚАЛАЙ ІСКЕ ҚОСУҒА БОЛАДЫ
1. ZIP файлды ашыңыз (Extract All / Барлығын шығару).
2. «index.html» файлын екі рет басыңыз — ойын браузерде ашылады. Интернет қажет емес.
3. Планшет/телефон: папканы көшіріп, index.html-ді браузерде ашыңыз.

БӨЛІМДЕР
📘 Үйрену               — квадрат/куб анимациясы, кесте, «Ақылман» ЖИ-көмекшісі.
⛷️ Шаңғы жарысы          — 5 деңгей (квадрат, куб, 7-тапсырма, өрнектер 2/3/9-тапсырма, ЖИ-жаттықтырушы).
📏 Сызба бойынша есеп    — 6-тапсырма: сызбаны оқу → «?»-ке сай сұрақ құрастыру → шешу.
                           Бірінші есеп дәл оқулықтағыдай (25 мин + 30 мин + ? = 70 мин).
✅ Ақиқат па, жалған ба?  — 8-тапсырма стилінде 60 секундтық сынақ.
🏆 Шеберлік картасы       — 15 факт, 100% → сертификат.

RU: Распакуйте архив и откройте index.html двойным щелчком. Интернет не нужен.
